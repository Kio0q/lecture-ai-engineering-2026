## 宿題

- 取り組んだレベル：発展（b）
- やったこと：Codespaces 環境に Pi を `npm install -g --ignore-scripts @earendil-works/pi-coding-agent` で導入し、Pi から Gemini に質問して起動を確認した。Pi の公開ソース [`system-prompt.ts`](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/src/core/system-prompt.ts) と `app/agent.py` の `INSTRUCTIONS` を比べた。
- 結果：Pi の既定プロンプトは「ファイルを調べ、コマンドを実行し、コードを変更するコーディングアシスタント」と役割を定め、利用可能なツールとその説明、ツール利用のルール、簡潔な回答、ファイルパスの明示、Pi のドキュメント案内などを含む。Pi に役割を尋ねると「プロジェクト内のファイルを調べ、コマンドを実行し、コードを書く／変更する」と回答した。一方、こちらの `INSTRUCTIONS` は AIE2026 の学習支援に特化し、用語集の確認、回の要約ツールの利用、推測で断定しないこと、関連する回の明記、宿題の答えではなくヒントを出すことを指示している。Pi のプロンプトには実行環境やプロジェクトに応じた情報も加わるため、固定の文章だけではない。
- 気づき・疑問：Pi は「何を操作できるか・どう操作するか」を広く定め、講座エージェントは「どんな根拠で、どんな学習支援をするか」を具体的に定めている。ツールの説明やプロジェクト指示もシステムプロンプトに組み込まれる点は共通している。Pi のプロンプトが選択モデルや有効なツールの構成でどう変わるかも、今後確認したい。
